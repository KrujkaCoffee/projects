# Выборка

## Частые фильтры

| Задача | Пример |
| --- | --- |
| Равенство | `Jurnal.filter(Номер_наряда=123)` |
| Список значений | `Jurnal.filter(Номер_наряда__in=[123, 124])` |
| Диапазон | `Jurnal.filter(Подытог__gt=0, Подытог__lte=480)` |
| Исключение | `Jurnal.exclude(Статус="Пауза")` |
| SQL NULL | `Jurnal.filter(Дата_выгрузки_ЕРП__isnull=True)` |
| Подстрока | `Jurnal.filter(Примечание__contains="ремонт")` |

>Условия `filter()` соединяются через AND.


## Ограничение выборки полей результата

```python
from project_cust_38.dynamic_db_models import Jurnal

qs = Jurnal.filter(
    Дата__gte="2026-11-01", Дата__lt="2026-12-01",
).order_by("-Штамп", "-Пномер")

rows = qs.values("Пномер", "ФИО", "Номер_наряда", "Подытог") # SmartList словарей SmartRow
row = rows[0] # SmartRow
```


## Получить результат

```python
objects = qs.limit(100).all()        # SmartList моделей: obj.ФИО
dicts = qs.limit(100).all(as_dict=True)
latest = qs.first()                # модель или None
exact = Jurnal.get(Пномер=123)       # исключение при 0 или >1 строке
count = qs.count()                 # COUNT(*) в БД
```

* `filter/order_by/limit` создают новый запрос. (т.е. их можно комбинировать без исполнения)
* `all/values/first/get/count` выполняют его; каждый вызов обращается к БД заново.

```python
row2 = Naryad.filter(123).first()
```


# `by_aliases()` меняет ключи результата для отображения.

```python
from project_cust_38.dynamic_db_models import Jurnal

rows = Jurnal.filter(Номер_наряда=123).values("ФИО", "Подытог")

display = rows.by_aliases({
    "ФИО": "Сотрудник",
    "Подытог": "Минуты",
})

if display:
    print(display[0]["Сотрудник"])
    print(display[0]["Минуты"])
```
