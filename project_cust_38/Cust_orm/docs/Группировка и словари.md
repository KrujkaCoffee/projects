# Группировка и словари

## Подготовить данные

```python
from project_cust_38.Cust_orm import GroupByTypes
from project_cust_38.dynamic_db_models import Jurnal

rows = (
    Jurnal.filter(Дата__gte="2026-11-01", Дата__lt="2026-12-01")
    .order_by("-Штамп", "-Пномер")
    .values("Пномер", "ФИО", "Номер_наряда", "Подытог")
)
```

## Группы и первое вхождение

```python
groups = rows.group_by("Номер_наряда")   # {номер: [строки]}
first = rows.group_by("ФИО", mode=GroupByTypes.FIRST)
first = rows.deploy_dict("ФИО")         # короткая запись того же
by_id = rows.deploy_dict()              # ключ - primary key модели
```

В примере `first` содержит последнюю по `Штамп` запись каждого сотрудника: берётся первое вхождение в заданной сортировке. Без `order_by` выбор "первой" строки не определён. `FIRST/LAST` задаются через Enum, не строками.

## Суммы и отдельная колонка

```python
minutes = rows.sum_by("ФИО", "Подытог")    # {ФИО: сумма}
total = rows.get_column_sum("Подытог")    # общая сумма
ids = rows.get_column_values("Номер_наряда")
unique_ids = {x for x in ids if x is not None}
```

Суммы пропускают `None`. `get_column_values()` сохраняет повторы
